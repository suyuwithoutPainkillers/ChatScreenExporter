# 聊天记录屏幕 OCR 导出工具

这个工具会在 Windows 上读取你屏幕里的聊天窗口：截图、OCR 识别文字、自动滚动、去重，最后导出一个 TXT 文件。它适合微信、QQ、网页聊天等“无法直接导出但能在屏幕上看到”的一对一聊天记录。

请只用于你有权保存和整理的对话记录。

## 能记录什么

- 时间：来自聊天窗口中实际显示的时间标记。
- 谁发的：默认左侧为“对方”，右侧为“我”。
- 内容：文本消息。
- 图片、表情、视频、语音、文件：默认跳过占位文字。图片里如果本身包含文字，OCR 仍可能误识别出来，导出后建议复核。

注意：很多聊天软件不会给每条消息都显示完整时间。本工具不能恢复屏幕上没有显示的精确时间，只会让没有单独时间的消息沿用最近一次可见时间标记。

## 安装

1. 安装 Python 依赖：

```bat
install_deps.bat
```

或手动执行：

```bat
python -m pip install -r requirements.txt
python chat_screen_exporter.py doctor
```

2. 安装 Tesseract OCR。脚本会自动查找常见安装位置，例如 `C:\Program Files\Tesseract-OCR\tesseract.exe`，不强制要求当前命令行能直接运行 `tesseract`。

中文聊天需要 `chi_sim` 中文简体语言包。本工具会优先使用 `%LOCALAPPDATA%\TesseractOCR\tessdata` 里的语言包，也可以使用 Tesseract 安装目录里的语言包。装好后运行：

```bat
python chat_screen_exporter.py doctor
```

如果输出里能看到 `Tesseract` 和 `chi_sim`，就可以开始。

## 第一次使用

1. 打开目标聊天窗口。
2. 建议先滚到最新消息，也就是聊天底部。
3. 直接双击 `ChatScreenExporter.exe`。启动窗口里可以填写双方名字、选择保存位置、选择速度，并点击“框选聊天范围”。

也可以单独运行校准命令：

```bat
python chat_screen_exporter.py calibrate --self-name 我 --other-name 对方
```

4. 屏幕变暗后，用鼠标框选“聊天消息列表区域”。参考聊天窗口中间的消息流，只选气泡、头像和时间所在区域；不要选左侧会话列表，也不要选底部输入框。

配置会保存到 `config.json`。

## 开始导出

最简单的方式是直接双击：

```text
ChatScreenExporter.exe
```

从最新消息往上翻旧记录：

```bat
python chat_screen_exporter.py run --max-pages 1200 --direction up
```

也可以双击：

```bat
run_export.bat
```

运行后会先弹出启动窗口，让你填写：

- 我的名字是：右侧头像/气泡对应的人。
- 对方名字是：左侧头像/气泡对应的人。
- 读取范围：点击“框选聊天范围”后拖拽选择聊天消息区域。
- 保存到：选择 TXT 输出文件夹。
- 速度：默认“快速”；“稳定”更慢但更稳，“极速”更快但需要导出后多复核。
- 滚动方式：`整屏翻页` 一次翻一整屏，推荐 AI 识别；`滚轮滚动` 是旧的逐段滚动方式。
- 防漏重叠：整屏翻页后反向补一点重叠，减少两屏交界漏消息；默认 `3`。
- AI流水线加速：先快速截屏翻页，再并发发送给 AI 识别，速度更快；如果接口限流可降低 AI 并发数。
- 识别模式：`本机OCR` 离线识别；`AI识别(GPT)` 会把每屏截图发送给 OpenAI 视觉模型识别。
- OpenAI Key：仅 `AI识别(GPT)` 需要，可在这里临时填写，或提前设置系统环境变量 `OPENAI_API_KEY`。

这些设置会保存到 `config.json`，导出的 TXT 会直接使用填写的双方名字。

如果没有手动选择保存位置，导出的 TXT 会放在 `exports` 文件夹，例如：

```text
exports/chat_export_20260527_213000.txt
```

两年跨度的聊天可能需要很多屏，启动窗口里的“最多扫描屏数”可以调大。导出过程中会出现控制窗口，可以“暂停/继续”，也可以点“停止并保存”。停止后已经识别到的内容仍会写入 TXT。结束时会弹出结果窗口，显示保存路径，并提供“打开TXT”和“打开文件夹”。

如果某一屏只有图片、照片、表情、语音、视频或文件，AI 模式会跳过，不会写入聊天记录。普通单屏识别异常也会跳过并继续；如果连续多屏都异常，工具才会停止并保存已经识别到的内容。

## 常用参数

```bat
python chat_screen_exporter.py run --self-name 张三 --other-name 李四 --max-pages 2000 --scroll-clicks 6 --page-delay 0.8
```

- `--self-name`：右侧消息显示成谁。
- `--other-name`：左侧消息显示成谁。
- `--recognition-mode`：`ocr` 使用本机 OCR，`ai` 使用 OpenAI 视觉模型。
- `--ai-model`：AI识别使用的模型，默认 `gpt-4.1-mini`。
- `--ai-concurrency`：AI 流水线并发请求数，默认 `3`。
- `--ai-batch-size`：每次 AI 请求合并识别几张截图，默认 `3`。
- `--ai-image-max-width`：发给 AI 前把截图压缩到的最大宽度，默认 `1280`。
- `--ai-image-quality`：发给 AI 的 JPEG 质量，默认 `82`。
- `--no-ai-pipeline`：关闭 AI 流水线，回到一屏一识别的串行模式。
- `--no-start-dialog`：本次运行不弹出名字确认窗口。
- `--hide-start-dialog`：保存配置，以后默认不弹出名字确认窗口。
- `--show-start-dialog`：保存配置，以后默认弹出名字确认窗口。
- `--max-pages`：最多扫描多少屏。
- `--speed-preset`：速度预设，可选 `稳定`、`快速`、`极速`。
- `--scroll-mode`：`page` 整屏翻页，`wheel` 滚轮滚动。
- `--page-overlap-clicks`：整屏翻页的防漏重叠量，默认 `3`。
- `--scroll-clicks`：每次滚轮滚动多少格。
- `--page-delay`：每次滚动后等待多久，电脑慢或聊天软件加载慢就调大。
- `--select-region`：运行前重新框选聊天区域。

## OCR 效果建议

- 聊天窗口尽量放大，字体不要太小。
- 不要让其他窗口遮挡聊天区域。
- 如果识别漏字，把 `--ocr-scale` 调高一点，例如 `--ocr-scale 2.0`。
- 如果识别很多杂字，把框选区域缩小，只保留聊天消息列表。

## 输出格式

```text
[2025年5月1日 20:31] 对方：晚上吃饭了吗
[2025年5月1日 20:31] 我：吃过了
```

每条消息一行，多行消息会用 `\n` 表示换行。
